* Презентация: React‑компонент Home
1. Общая идея
Технологии: React, TypeScript, React Router, i18next

Назначение: главная страница приложения с поиском направлений

Основные элементы:

Фоновое изображение с затемнением

Заголовок и подзаголовок (многоязычные)

Поле поиска и кнопка

2. Международализация (i18n)
Используется useTranslation() из react-i18next

Все тексты (slogan, hero_text, search_placeholder, search_button) берутся из словарей локализации

Преимущество: поддержка нескольких языков без изменения кода

3. Управление состоянием
useState хранит значение поискового запроса (query)

Поле ввода — контролируемый компонент

При изменении текста обновляется состояние

4. Навигация
useNavigate из react-router-dom

Функция handleSearch():

Проверяет, что строка не пустая

Перенаправляет на /destinations?search=<запрос>

Преимущество: чистые URL‑параметры для поиска

5. Интерфейс и стили
Используются inline‑стили для секции и элементов

Фоновое изображение с затемняющим слоем (overlay)

Центрированный контент с максимальной шириной

Поле ввода и кнопка стилизованы для удобства

6. Преимущества архитектуры
Простая и понятная структура

Поддержка многоязычности

Чистая навигация через URL

Современный и удобный интерфейс
